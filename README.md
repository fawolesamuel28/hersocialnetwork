# Her Social Network CIC

Static website structure for Her Social Network CIC.

## Project structure

- `index.html` - main homepage file
- `assets/css/style.css` - combined stylesheet
- `assets/js/main.js` - site interactions and mobile menu behavior
- `assets/images/` - image assets and placeholders

## Notes

- Fonts are loaded from Google Fonts via the HTML head
- The mobile menu toggle is handled in `assets/js/main.js`
- Move any real photos into `assets/images/` and update the markup accordingly
